# setembro-amarelo
O **Acolhe** é uma aplicação web desenvolvida como projeto acadêmico de ADS para o **Setembro Amarelo**, com o objetivo de promover conscientização sobre saúde emocional e facilitar o acesso a informações e canais de apoio.

A plataforma oferece recursos interativos, como um espaço para registrar como o usuário está se sentindo, mensagens de acolhimento e um exercício de respiração guiada. Também apresenta informações sobre onde buscar ajuda, incluindo o CVV pelo número 188, CAPS, unidades básicas de saúde e clínicas-escola.

Desenvolvido com **HTML5, CSS3 e JavaScript**, o projeto possui uma interface responsiva e acessível, adaptada para computadores e dispositivos móveis. A aplicação tem finalidade exclusivamente educacional e não substitui acompanhamento psicológico, médico ou atendimento profissional especializado.
